# TokenPilot for Grok Bot

- Preserve native tools, memory, connectors, permissions and task scope. Search narrowly, read required sections, batch independent work and keep conclusions concise.
- Make the smallest complete change. Run required checks together when safe, expose failures, repeat only affected checks and stop after verification.
- For savings, compare the same real task with and without the workflow. Both results must pass the same checks, and official numeric usage must cover all parent-Bot input and output, including cached input and compaction. Reasoning is an output subset.
- Show only the measured percentage. Missing or incomplete parent-Bot metrics mean `Reduction unavailable`. Never substitute cache reuse, weekly quota percentages or Grok Build subprocess usage.
- Grok Build CLI results: https://github.com/cesaremcasa/tokenpilot/blob/main/docs/GROK_RESULTS_2026-10-06.md. These are task-specific CLI observations, not a savings guarantee for this Bot.
