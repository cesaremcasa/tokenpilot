# Grok Bot integration

Research scope: all 21 Grok Bot pages listed in the [official documentation index](https://docs.x.ai/llms.txt), plus the linked Cursor OpenTelemetry overview and wire reference, reviewed October 6, 2026. This is an integration proposal; it is not a deployed Bot adapter or measured Bot savings.

1. **Start with the private skill.** Save [TokenPilot](../integrations/grok-bot/tokenpilot/SKILL.md) in the Bot's private skills library and verify it in the `/` menu. That library is shared across Bots. Local `~/.grok/skills` belongs to Grok Build and does not establish cloud-library installation. [Skill documentation](https://docs.x.ai/grok-bot/skills-routines-and-automations).
2. **Use the supported terminal.** Keep the package and result artifacts under `/workspace/tokenpilot`. Install the verified npm release on the cloud computer; local-computer execution is a separate capability with its own approvals. Cursor manages the parent Bot's model, so CLI reasoning flags do not configure that parent. [Computer and apps](https://docs.x.ai/grok-bot/computer-and-apps), [settings](https://docs.x.ai/grok-bot/settings-and-notifications).
3. **Keep measurement scopes separate.** TokenPilot can measure supported Grok Build subprocesses. Their counters, subscription-quota percentages and estimated costs do not prove parent-Bot token reduction. Individual-account parent savings remain unavailable without an official complete correlated channel.
4. **Enterprise has an official measurement route.** Cursor Enterprise can export OTLP/HTTP protobuf. Prefer numeric `cursor.api.request` records with `cursor.surface=grok_bot`, Bot/conversation and turn identifiers. Deduplicate `cursor.event.id`; never combine these logs with metric totals. Validate cache-counter semantics, compaction and delegated-call coverage before comparing equivalent tasks. Leave conversation-content export disabled. [Export overview](https://cursor.com/docs/enterprise/opentelemetry-export), [wire reference](https://cursor.com/docs/enterprise/opentelemetry-export/wire).
5. **Keep the first build small.** Private skill plus cloud-terminal CLI is the first usable integration. An Enterprise receiver is a separate next step once entitlement and sample coverage are verified. The reviewed Bot documentation does not establish a public API for installing private skills or controlling the existing Bot. The Cursor agent SDK is a distinct runtime, not proof of access to a signed-in Grok Bot desktop account.
